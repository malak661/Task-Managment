# Task Board

A small team task board: sign in, create projects, add tasks, hand them to a teammate
and watch the status move from To Do to Done.

- `backend/` — Node.js + Express REST API on top of MongoDB
- `frontend/` — React single page app (Vite)

Setup instructions and the API reference are written up further down as the project
grows. For now:

```bash
cd backend
cp .env.example .env
npm install
npm run dev
```
